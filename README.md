# Portfólio · Leonardo Fernandes

Site estático publicado na Vercel: https://leonvrdof.vercel.app

Cada página tem endereço próprio (`/lia`, `/tom`, `/drogaria`, `/petgram`, `/assai`, `/sobre`). São cópias do mesmo site, cada uma com título e descrição próprios, e a Vercel serve `lia.html` em `/lia` (`cleanUrls`). Links antigos com `#` (`/#lia`) são levados ao endereço novo.

Os protótipos da Lia e do Tom rodam dentro dos celulares dos cases, pelo modo vitrine (`?modo=vitrine`) dos sites deles.

Estes arquivos são gerados. O código-fonte fica na pasta `fonte/` do projeto (`build.py` e depois `site.py`); não edite os `.html` daqui à mão.
